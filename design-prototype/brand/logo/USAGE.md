# YONDO logo — usage guide (draft v0.1)

Direction: A (two converging lines + nodes). Theme-adaptive: pick the file by background.

| Background | Files (suffix) |
|---|---|
| Warm paper `#F5F2EC` / white | `-light` |
| Ink `#111111` | `-dark` |
| One-colour print, embroidery, fax (light bg) | `-mono-black` |
| One-colour on dark | `-mono-white` |

Forms: `symbol`, `symbol-small` (≤24 px), `horizontal`, `stacked`, `app-icon`, `favicon.svg` (adapts to OS light/dark). Wordmark is **outlined paths** (Space Grotesk Bold, no kerning applied). The symbol is built from strokes and circles, **not outlined yet**.

## Colour
Ink `#111111` / `#F5F2EC` · Accent `#E8501A` (graphic only: 3.36:1 on paper, 5.03:1 on ink; never as text). Mono versions replace the accent dot with a hollow ring.

## Clear space & minimum size (proposed, screen-tested only in the size sheet)
- Clear space = diameter of the top node (≈ 22% of symbol height) on all sides.
- Minimum: symbol-small 16 px · symbol 32 px · horizontal 96 px wide · stacked 64 px wide. Print/embroidery minimums are **not tested**.

## Incorrect use
1. Recolouring the accent node or using it as text colour.
2. Stretching, rotating or skewing.
3. Adding gradients, shadows or outlines.
4. Placing the colour version on busy photos or low-contrast backgrounds.
5. Retyping the wordmark in another font.
6. Using the full symbol below 24 px instead of `symbol-small`.

## Similarity review (not trademark clearance)
No search of trademark registers was done. The mark is a Y-fork with nodes, a generic structure; it may resemble tuning-fork, stethoscope, network or git-branch icons. Legal clearance is recommended before launch.

## Known limitations
No kerning on the wordmark · symbol not outlined · embroidery/print feasibility not tested · no real-device rendering check.
