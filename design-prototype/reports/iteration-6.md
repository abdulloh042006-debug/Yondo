# Iteration 6: product decisions D1–D5 and backend audit
**Critique (defects found).** (1) Prototype sent a companion profile id as `reported_user_id`: the real backend answers 404, and the mock wrongly accepted it. (2) Mock defaulted to an invented 10% platform fee. (3) Mock accepted partial availability filters and skipped validation; preview worked with an empty cart (real: 409). (4) Float-based money formatting mis-printed int64 max; price inputs multiplied floats. (5) Real-API error envelope is flat (`code` at top level); reporter id extras are forbidden.
**Changes.** Mock aligned with the real backend (containment, tz-aware intervals, ID matrix, flat envelope, empty-cart); fee policy unconfigured by default with a labelled DEMO fixture; BigInt/exact money parsing; customer-side report/block replaced by an explanatory dialog; fees shown only from API responses and separately; decisions documented with a proposed OpenAPI overlay; backend characterization tests (50) against the real app on SQLite and PostgreSQL 16.
